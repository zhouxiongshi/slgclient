# 六大体系闭环设计方案（待确认）

> 2026-11-12 · 针对 6 个实机反馈问题的整体设计。
> 原则不变：原画面逐字节保留，全部走 DOM 覆盖层 + 服务端注入；战法原文来自 battle-kit 不改写；battle-core 确定性内核不动。

## 0. 六个问题的现状诊断（先说清楚现在缺什么）

| # | 问题 | 现状 | 缺口本质 |
|---|------|------|----------|
| 1 | 无势力选择/争霸入口，行军无动画无速度 | 出征是**瞬时到达**（`canMarchBetween` 只做校验）；开局直接在城里，没有选势力环节 | 缺「过程」与「选择」——玩家感觉不到自己在打仗、在争霸 |
| 2 | 诸侯势力地图上分不清 | 72 城归属数据全有（`state.strategy.cities[].owner`），但地图上只画了城点，没有势力色/旗 | 纯表现层缺失，数据现成 |
| 3 | 面板不闭环 | 六面板都有 UI，但大多是「查看器」：内政委任不生效、兵刃锻造不接战斗、技能学了用不出 | 缺「操作→生效→反馈」回路，每个面板只有半截 |
| 4 | 武将数值失衡、技能描述不清、战报没入口 | 战报链路完整（`handlers.js:957` 原版战报已推送并存档）；技能有原文但没结构化描述，装配了不进战斗 | 战报**有数据无入口**；技能**有文本无语义** |
| 5 | 资源乱 | `economy.js` 已有五资源、日产、军饷（每兵维持费），但消耗端（建筑/征兵/研习）没接全，玩家看不到钱花哪了 | 缺「用途表 + 收支流水」两个呈现层 |
| 6 | 武将职业不明确 | 936 武将五维数据齐全（characters.csv），但没归类、没岗位分工、没职业成长 | 缺「五维→职业→岗位→技能池」的映射层 |

**关键判断：六个问题里只有两件事需要新系统（行军过程、技能进战斗），其余四件都是「数据已有、补表现和接线」。**

## 1. 势力选择 + 争霸入口 + 行军系统（问题 1）

### 爆款怎么做的（实测过的结论）

- **《三国志·战略版》**：开局先选「主公类型」（贤主给铜币/英主给战法点，不同开局资源取向），再选**出生州**——巴蜀资源均衡、西凉骑兵移速、河北枪兵、江东弓兵，每个出生州带差异化加成。这条流程实测打磨过：**先给身份差异，再给地缘差异**，玩家两次小选择而不是一次大选择，降低决策压力。
  - 来源：dianwantu.com/a/38511、123syg.com/newszx03/230886
- **《全面战争：三国》**：势力选择即战役选择——选哪个诸侯直接决定初始城池、初始武将团、专属科技线。**选势力 = 选玩法**。
  - 来源：baike.baidu.com/item/三国全战争/2149802
- **行军模型**（SLG 数值通用结论）：
  - 行军时间 = 距离 ÷ 速度，速度由**兵种**决定，与武将面板无关；同类游戏统一「每格耗时」制（三战：枪盾弓 15 秒/格、骑兵 10 秒/格、器械 30 秒/格），**速度差异不宜过大**，否则支援体系崩坏。
  - 地形影响体现在**时间**上而不是属性上（森林减速、山地绕行），用时间制造战略纵深：行军久 = 支援慢 = 防守方有反应时间。
  - 行军是「战斗节奏的调速器」：控制冲突频率，是数值调优最安全的旋钮。
  - 来源：欧米《SLG数值思路分享⑨ 行军与地形影响》（mp.weixin.qq.com）、lehui033.com/gamezx01/13427

### 我们的设计

**① 开局「举义」页（新）**：首次进入游戏（无存档时）弹出全屏举义页，两步选择：
1. **择主**：8 家诸侯各一张卡（势力色 + 专属技 + 初始武将团 3 人 + 玩法一句话，如「曹操·挟天子：政务+10%，虎豹骑」）。借鉴全战「选势力=选玩法」。
2. **择都**：该诸侯控制区内 3 座候选城（近资源型 / 近关隘型 / 远离强敌型），对应三战出生州逻辑。

不做主公答题（单机不需要铜币/战法点的投放仪式），直接给差异化初始包。

**② 争霸入口**：顶栏常驻「天下大势」按钮 = 现有战略台；战略台内加「举旗」页签，显示统一进度（城池占有 / 天命值），即胜利条件可视化。

**③ 行军系统（本方案最大的新系统）**：
- 出征不再瞬时：生成行军队列 `{armyId, path:[城id...], departDay, arriveDay, state:'marching'}`。
- **时间公式**：`天数 = Σ(段距离 ÷ 兵种速度)`。相邻城 1～3 游戏日；骑兵 1 日/城、步弓 1.5、器械 2.5（差异保持 ≤2.5 倍，符合「速度不宜过大」实测结论）。关隘被封锁 = 不可出发（校验已有）。
- **地图动画**：城市坐标在 `detail.json` 行军节点里现成。客户端按 `arriveDay - departDay` 插值插旗/军标沿路径移动，一次出行军线（虚线 + 旗帜小标，借鉴三战「行军虚线可被预判拦截」的视觉语言）。
- 到达结算走既有 battle-core + 原版战报，进攻方行军途中显示倒计时；被攻打方的来犯预警复用现有 `来犯军` 通道。
- 暂不做途中拦截/撤退（三战级玩法），先做「看得见的行军」，拦截放二期——行军一旦有时间成本，拦截是自然延伸，但一期先保闭环。

**验收**：选曹操开局能看到专属技和初始武将团；点出征后地图上军标沿路移动 30～90 秒（真实时间随游戏钟缩放）后触发战斗并出战报；关隘封锁的城无法出征。

## 2. 势力旗帜与地图势力区分（问题 2）

### 爆款怎么做的

- **《全面战争：三国》**：大地图用**色码边界**区分势力——己方深绿、盟友青、敌对红、中立白，一眼分敌我；小地图同规则（友军绿/敌军红/未知灰）。颜色同时编码**外交关系**和**归属**两层信息。
  - 来源：totalwar.fandom.com/wiki/Commandery、baike.baidu.com
- **《三国志11》**：每家势力固定专属色，城市/部队全部染色，系列沿用 20 年，玩家已建立颜色直觉（曹操蓝、刘备绿、孙家红——业界惯例色）。

### 我们的设计

- **八诸侯标准色**（沿用业界直觉色）：曹操 #2E5FA3 青、刘备 #3D8B4F 绿、孙权 #C0392B 赤、董卓 #4B4B4B 皂、袁绍 #7C5CBF 紫、袁术 #D4A017 金、马腾 #B87333 骝、刘表 #2B8C8C 苍。玩家所在势力加金色描边高亮（借鉴全战「己方特殊色」）。
- **旗帜样式**：每城上插**燕尾小旗**（SVG）：旗面 = 势力色 + 诸侯姓氏单字（曹/刘/孙…），旗杆阴影贴城点。空城插灰旗无字。**旗帜漂亮的关键**：旗面带轻微波浪动画（CSS transform 循环）、金色旗杆头、玩家旗更大一号。比对同级游戏，燕尾旗 + 单字是辨识度最高、实现最轻的方案。
- **战况层**：行军线颜色随行军方势力色；交战中的城点闪红圈。
- 图例常驻左下角：八色 + 当前势力标注。

**验收**：打开全屏地图 3 秒内能指出曹操/刘备/自己的地盘；旗帜动画帧率不掉（≤72 个 SVG 节点，实测无压力）。

## 3. 面板闭环（问题 3）

### 爆款怎么做的（闭环的共同范式）

三战每个面板都是同一条回路：**入口 → 消耗清单 → 确认 → 生效（数字立刻变）→ 反馈（流水/红点）**。玩家永远知道「花了什么、得到什么、在哪能看到」。
- 城建：消耗木材石料 → 建筑升级 → 产量上限提升 → 仓库可见。
- 征兵：消耗粮铁铜 → 兵力上升 → 兵营等级定上限。
- 战法：铜币/战法点 → 研习 → 学会 → 配将 → 战报里看到它发动。
  - 来源：sogou 百科《三国志·战略版》资源/城建条目、zhixun311.com/gamezx01/14074

**反例（不采纳）**：率土的宝物系统、三战的装备回报无感——我们此前方案已定红线「装备单件 ≤8%、全套 ≤25%」，保持。

### 我们的设计：六面板逐个闭环

| 面板 | 闭环（一条链走完） | 现有底子 |
|------|--------------------|----------|
| **内政** | 委任武将到岗位 → **产量加成立即体现在日产数字上（delta 可见）** → 设施升级（消耗木/石）→ `*_yield` 上调 → 次日产入账 → 仓库流水可查 | 委任 UI 有、产量字段有，缺「生效接线 + 升级」 |
| **武将** | 查看五维 → 「编队」按钮直接跳出征选择 → 「装备」跳兵刃穿戴 → 升级经验来源 = 战报 | people.js/dossier.js 有，缺跳转链 |
| **仓库** | 五资源 + 上限 + **近 20 条收支流水**（哪天、花了啥、为什么）——这是资源不乱的根 | economy.js 有账本位，缺流水记录与呈现 |
| **兵刃** | 锻造（消耗铁+金币）→ 入库 → 穿戴（单件 ≤8%）→ **战报里可见加成伤害** |锻造已有，缺「战报中可见」的反馈闭环 |
| **技能库** | 研习（残卷+铜币）→ 学会 → **装配到武将槽（每人 ≤2 条）** → 战斗真实触发 → 战报显示发动 | 研习已有；装配与触发是本次新接（见 §4） |
| **战略** | 选目标城 → 出征（新行军系统）→ 行军动画 → 战报 → 下一目标 | 战略台有，接 §1 行军 |

**统一反馈规范**：所有面板操作成功后，右上角 toast 显示「+产出/−消耗」绿色/红色明细；仓库流水即刻可查。这是三战「操作即反馈」的照搬。

**验收**：不开攻略，从任一面板出发能不看文档完成一次「花钱→生效→在别处看到结果」的完整操作。

## 4. 武将数值 / 技能语义 / 战报入口（问题 4）

### 爆款怎么做的

- **《三国志11》五维体系**（20 年验证的标杆）：统率=部队防御、武力=攻击、智力=计略攻防、政治=内政效果、魅力=登用/征兵。**明确不建议五项全能武将**，按定位偏科分配才有趣；总值 250～350 区间为一流武将，顶级（吕布/诸葛亮）到 370+。
  - 特技是「超越属性的质变」：关羽神将、诸葛亮神算、赵云洞察——**每个特技描述一句话说清触发条件与效果**。
  - 兵种适性 S/A/B/C 决定战法可用性。
  - 来源：7longwen.com、1771314.com/e/san-guo-zhi-tui-jian-ren-cai.html
- **战报**（《鸿图之下》《英雄文明》）：
  - 分六类标签：全部/扩张/交战/攻城/侦察/收藏；每条战报标注攻方剑图标/守方盾图标。
  - 详情页三层：**战果层**（胜负、兵力损耗、坐标）→ **技能层**（每条战法发动次数/伤害/治疗）→ **统计层**（总伤害、控制触发次数）。
  - 战报是 SLG 的「学习工具」：玩家靠战报反推阵容问题。
  - 来源：33game.com.cn 鸿图之下战报解析、fxcyysc.com 三国志战略版战斗查看

### 我们的设计

**① 数值归一**：把 characters.csv 五维（已有）做一次校准 pass：
- 主属性定位：统率>85 或五维最高=统帅；武力最高=猛将；智力最高=军师；政治/魅力最高=政务官（详见 §6）。
- 平衡带：一流 300±30，超一流 340+（吕布/诸葛亮/曹操），普通 220~270。与 battle-core 伤害公式联调，目标「同级对战胜负 <60% 倾向、跨级有克制」。

**② 技能语义化**：为 51 条 battle-kit 战法生成结构化描述卡：`{类型: 主动/被动/指挥, 目标: 敌单体/全体/自身, 效果: 伤害120%/治疗30%/控制1回合, 发动率: 35%, 来源: 师承-关羽}`。**原文保留在卡片详情**，列表页显示语义摘要。类型/发动率从 battle-core 代码反推，保证描述与实际结算**永远一致**（杜绝「描述骗人」）。

**③ 技能进战斗**（接 battle-core）：
- 装配槽：每将 ≤2 条战法（此前已定红线）。
- 结算接入：主动技按发动率在回合内 roll（走 battle-core 现有 rng，保持确定性指纹）；被动常驻；指挥战前生效。event_fingerprint 机制天然支持回放验证。

**④ 战报入口**：
- 顶栏加「战报」按钮（剑盾图标）→ 列表页（全部/进攻/防守/攻城 三标签，借鉴鸿图）→ 点击进详情：**复用原版战报面板组件**（`handlers.js:957` 已推的原版战报数据直接喂给原组件，零改造），下方补一层我们自己的统计条（我方战法发动次数/伤害占比——battle-core 事件流里现成）。
- 有未读战报时按钮加红点。

**验收**：战斗后顶栏红点 → 点开战报 → 看到每条战法「发动了什么、打了多少」；技能描述页与战报实际结算一致（同一战法两处数值相同）。

## 5. 资源闭环（问题 5）

### 爆款怎么做的

- **《三国志·战略版》五资源各有唯一用途**（sogou 百科）：木材/铁矿/石料 → 建筑城建；木材/铁矿/粮食 → 征兵；粮食额外承担**行军/军饷消耗**（部队越多吃得越多——兵是持续负担）；铜币 → 招募/战法点/锻造。**每项消耗都有明确归属**，玩家不会问「这资源干嘛的」。
- **仓库上限**逼玩家主动消费（爆仓=产量浪费），形成「产出→消费→再产出」节奏。
- 阶段性产量配比（开荒 2:2:1:0.5 → 交战期抬粮）是运营侧调参手段，单机版简化为「按玩家兵力/建设进度动态倾斜」。
- 来源：baike.sogou.com/v183324481、dipingcn.com/dizx01/30743

### 我们的设计

**① 用途总表（一次说清）**——仓库面板顶部常驻：

| 资源 | 产出 | 消耗 | 玩家一句话 |
|------|------|------|-----------|
| 木材 wood | 属地+伐木场+委任 | 建筑、设施升级 | 「盖房子用的」 |
| 石料 stone | 属地+采石场+委任 | 城墙、城防、关隘修缮 | 「修城墙用的」 |
| 铁矿 iron | 属地+冶铁+委任 | **锻造兵刃、征兵** | 「打装备招兵用的」 |
| 粮草 grain | 属地+农田+委任 | **征兵、军饷（每兵每日）**、行军耗时折损 | 「养兵用的，兵越多吃越多」 |
| 铜币 gold | 税赋+民居+委任 | **战法研习、招募武将、俸禄** | 「学技能招人才用的」 |

**② 接全消耗端**（代码级）：
- 征兵：消耗 `grain × 兵数 × 系数 + iron × 兵数`，兵营等级定单次上限。
- 行军：出发扣 `grain × 兵力 × 距离 × 0.1`（远征有代价，呼应 §1 行军时间）。
- 俸禄：每委任武将每日 `gold × 品级`（让委任有成本、政治值有回报）。
- 研习/锻造：已有，纳入统一扣费通道。

**③ 收支流水**：`state.resLedger[]` 每笔 `{day, res, delta, reason}`，滚动保留 200 条。仓库面板画三条线：今日产出 / 今日消耗 / 净变化，最近流水列表。**这是治「资源乱」的药引——玩家第一次能回答「我的粮怎么没了」**。

**④ 上限与爆仓**：`depot_capacity` 已有；产出顶格时仓页面给黄色警示「爆仓：产量浪费中」。

**验收**：征一次兵、盖一个设施、打一次远征后，仓库流水里能看到三笔带原因的记录；兵力翻倍时军饷消耗肉眼可见地翻倍。

## 6. 武将职业体系（问题 6）

### 爆款怎么做的

- **《三国志11》**：五维 + 特技 + 兵种适性三件套；「全能武将不有趣，偏科武将才有玩法」；内政武将配「能吏/名声/繁殖」后勤特技，战斗武将配「霸王/飞将/神将」，谋士配「神算/连环/火神」。
- **《全面战争：三国》**：四大职业原型——**武士（金，近战输出）、指挥（木，军队增益）、军师（水，计略/远程）、先锋（火，冲锋）**；每职业专属技能树 + 专属岗位（军师才能当谋主、指挥才能总督全军）。
  - 来源：baike.baidu.com（五行科技/官职）、totalwar.fandom.com（Administrator 按职业给不同 buff）

### 我们的设计

**① 四职业树**（由五维自动判定，936 人全覆盖）：

| 职业 | 判定（主属性） | 出征岗位 | 内政岗位 | 专属技能池方向 |
|------|----------------|----------|----------|----------------|
| **统帅** | 统率最高且 ≥80 | **主将**（部队防御/上限） | 太守（城防+驻军上限） | 军团增益、守城 |
| **猛将** | 武力最高且 ≥80 | 先锋/副将（伤害核心） | —— | 单体爆发、突击 |
| **军师** | 智力最高且 ≥80 | 军师随军（计略/控制） | —— | 计略、火攻、减益 |
| **政务官** | 政治/魅力最高 | —— | 各委任岗（产量加成） | 内政特技、招募 |

无 ≥80 主属性的归「干才」（低配版，仍可上岗但加成低）。玩家在武将面板一眼看到职业徽章。

**② 岗位挂接**：出征编队强制三人形（主将=统帅/猛将、军师位、副将位）；内政委任只能由政务官/统帅担任且加成按对应属性算（把现有「内政委任 ≤30%」红线挂到属性上）。**岗位限制就是职业的意义**——参照全战「Administrator 按职业给不同 buff」。

**③ 诸侯特色**（8 家各一条专属技 + 初始班底，接 §1 开局）：曹操「挟天子」（政务+10%）、刘备「仁德」（登用/民心）、孙权「据长江」（水路行军快）、董卓「暴政」（抢掠获得双倍但民心降）、袁绍「四世三公」（初始武将团 5 人）等——全部可从 characters.csv 历史事实派生，不编造。

**④ 成长闭环**：武将经验只来自战报（出征/守城），政务官经验来自委任天数——职业决定经验来源，形成「用谁谁强」的矩阵（三战「队伍分工」的精髓）。

**验收**：武将面板有职业徽章；委任政务官产量比委任猛将高且数字不同；出征编队不满足主将条件时给出明确提示。

## 8. 直接拿来用的十条（实测检验过的硬结论）

1. 开局两次小选择（身份→出生地）优于一次大选择 —— 三战。
2. 选势力 = 选玩法：诸侯卡直接写差异化初始包 —— 全战三国。
3. 行军速度差异控制在 2.5 倍以内，超了支援体系崩 —— SLG 数值共识。
4. 地形影响走时间不走属性 —— SLG 数值共识。
5. 每资源一个唯一主用途，用途表常驻面板 —— 三战。
6. 仓库上限逼消费，爆仓警示 —— 三战。
7. 收支流水让玩家回答「钱花哪了」 —— 通用 SLG 后台实践。
8. 战报三层结构（战果/技能/统计）+ 分类标签 + 红点 —— 鸿图/三战。
9. 特技描述一句话说清触发条件与效果，描述必须与结算一致 —— 三国志11。
10. 职业的意义在岗位限制，不在数值差异 —— 全战三国。

## 9. 我们的独有亮点（差异化，别人没有的）

1. **确定性战报回放**：battle-core 的 `event_fingerprint` 让每份战报可逐字节重放——同类网游做不到（服务端不回传全量事件），单机版独占卖点。
2. **936 人全量武将库**：接 characters.csv 真实数据，四职业自动判定，规模远超同类单机。
3. **关隘行军网**：72 城 + 73 关隘的真实地理路网（汉末 140 年郡县底图），比同类「格子地图」更有历史质感；关隘封锁即断路，是天然的战役剧本生成器。
4. **战略脑与玩家同一套规则**：NPC 诸侯用同一张行军网、同一个资源约束，玩家可以「看得懂敌人为什么这么走」——AI 透明化在 SLG 里罕见，教学价值极高。
