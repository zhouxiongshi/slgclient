# 九大系统扩展设计方案（待实施）

> 2026-11-12。承接《六大体系闭环设计方案》：举义页已上线（d8f75d0），玩家反馈「举义后不知道怎么玩」。
> 本方案只借鉴**同类型、与现有系统不冲突**的设计，每条标注来源与落点。

## 借鉴来源与取舍

| 系统 | 借鉴对象 | 采纳要点 | 不采纳 |
|---|---|---|---|
| 编队/出征 | 三国志战略版、率土之滨 | 主将+副将同槽上阵、兵力按兵种槽分配、编队可换将 | 站位追击格（格子战法体系我们不存在，硬搬=拼凑） |
| 兵种克制 | 三国志战略版 | 克制环 ±15% 出入伤 | 五兵种+器械（本作只有 3 兵种槽，扩到 5 会牵动内核） |
| 兵种适性 | 三国志战略版 | 适性决定武将属性发挥（S=120%…） | 配置表 S/A/B/C 分档（原 conf 无此数据，改为五维派生连续系数） |
| 忠诚/俸禄 | 三国志11 | 每旬自然-1；俸禄挂钩；欠饷加速掉忠；赏赐+忠；低忠叛逃 | 相性/结婚/结义/官爵（人物关系网工程量失控） |
| 城市差异/人口 | 三国志14 | 每城农/商开发度决定产出；人口自然增长、募兵吃人口；收支恶化→忠诚降 | 涂色占地/府级格子（地图体系不同） |
| 战争→经济 | 三国志11/14 | 欠饷→忠诚降→士兵流失；战利品掠夺；围城产出减半；城破人口损失 | 厌战度/战争支持度（P 社系，与单机 SLG 节奏不符） |
| 运输 | 三国志11/14 输送队 | 运输队走行军队列送达城库；蝗灾前运粮避损（经典应对） | 辎重车队被劫（野战拦截体系不存在） |
| 灾害 | 三国志11 | 蝗灾（吃粮）/瘟疫（减兵）/丰收（粮+）；概率事件；政务官减免 | 特技风水/祈愿（用现有职业体系替代） |

## 分期

### P0 编队与兵种克制（三战口径，落 strategy.js/battle.js）
- **编队**：`army.formup {armyId, generals:[3], soldiers:[3]}`——选将上阵/换将/按兵种分配兵力。约束：武将不可重复入队；槽位 i 即兵种 i（1盾步/2弓/3骑）；出征/行军中不可改。
- **适性**（`armsApt(g, armsIdx)`）：盾→defense、弓→strategy、骑→force 按五维派生。
  ⚠️ 实施修订：适性**不做内核数值折算**（守军 NPC 配置五维普遍高于开局玩家武将，对称折算会净增强守军、破坏「两将 1200 兵打 1 级城」的平衡基线，实测验证），只在编队 UI 作为「该兵种下属性发挥参考」展示；克制 ±15% 在战略层实际生效。
- **克制环**：骑(3)→盾(1)→弓(2)→骑(3)，±15%。在 `settleArmyBattle` 战略层折算参战兵力，战报注明「兵种克制」，不动内核确定性。
- **UI**：队伍卡显示武将+兵种+适性条+对目标城守军兵种的克制提示；编队弹窗。

### P1 忠诚与俸禄（三国志11口径，落 economy.js/panels.js）
- `general.loyal` 初始 82~92（camp 契合微调）。每旬（10 日）：普通武将 -1；在委任岗位 +0.5 不减。
- **旬俸**：每旬发 `20×star` 金（滚动俸禄）；资金不足 → 欠饷：该旬忠诚 -5，流水记「欠饷」。
- **赏赐**：`general.reward {id, amount}` 金 -amount、忠诚 +amount/100（上限 +15/次）。
- **叛逃**：忠诚 <70 每旬 3% 概率、<40 每旬 10%——武将离队回酒馆池，事件播报。忠诚=0 不再战斗减员，只做人事压力（避免战斗体系被污染）。
- UI：武将卡忠诚色条、赏赐按钮、俸禄/忠诚规则说明。

### P2 城市差异·人口·逐城产量（三国志14口径，落 city-econ.js/economy.js）
- 新 `domain/city-econ.js`（零依赖）：每玩家城 `st.cityEcon[cityId] = {pop, devAgri, devTrade, store}`，初始值取 detail.json 的 population / 农业属性 / 商业属性。
- **逐城日产**：粮 `6×(devAgri/50+1)`、金 `4×(devTrade/50+1)`；特产加成（铁→iron、盐金→gold、粟→grain）。玩家总产=Σ己方城，替换 applyDays 现行全局一刀切，流水口径不变。
- **人口**：每 30 日 pop×+4%（上限 10 万）；征兵每兵吃 1 人口；城破 pop -15%。兵源 attr 修正该城可募上限。
- **开发**：农田升级→devAgri+5/级、市场→devTrade+5/级（挂现有设施升级链）。
- UI：城池经营面板（人口/产出/开发度/特产/灾害风险列），产出明细进内政面板。

### P3 战争经济·运输·灾害（三国志11/14口径，落 strategy.js/economy.js）
- **战利品**：野战胜 → 金=歼敌×0.5、粮=歼敌×1 入池入流水「战利品」；攻陷城 → 一次性掠夺金粮大额。
- **城库存粮 + 运输队**：出征行军粮优先从出发城城库扣，城库不足吃全局池并 +25% 损耗（激励前线囤粮）；`strategy.transport {toCity, grain}` 走 marches 队列 2 日送达（type:'transport'）。蝗灾时运粮出城=经典避险操作。
- **灾害**：每旬每城掷骰（灾害风险 attr 修正）：蝗灾 3%（城库 -40%、当旬粮产减半）、瘟疫 2%（驻军 -10%、pop -5%）、丰收 4%（当旬粮产 +50%）。政务官在岗 → 全势力灾害概率 -20%（呼应职业体系）。事件进 chronicle + chat 播报 + 府库事件卡。
- **围城经济**：被围/易主战期间该城当旬产出减半。

## 与现有系统无冲突声明
- 资源仍是全局池 + 城库二级，流水/府库不动结构只加 reason。
- 内核（kernel/）零改动：克制在 settleArmyBattle 折算，适性在 makeUnit 前折算。
- 行军队列 marches 复用（transport 只加 type），到达结算复用 strategyResolveMarches。
- web/ 逐字节不动，全部走运行时注入。
