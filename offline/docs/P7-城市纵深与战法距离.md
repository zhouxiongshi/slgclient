# P7 城市纵深与战法距离

> 对应《功能检查报告-七项》的 P0~P3 全部事项。基线 `6d5842b`，本次一次落地。
> 工程红线照旧：`offline/web/` 逐字节不动、UI 走运行时注入、内核只加字段不改结算、旧档 `normalizeWorld` 兜底。

## 一、修掉的两个 P0

### Bug A：出征只能从首都出发
- `strategyAttack` 新增 `fromCityId`（缺省回落 `st.playerCity`），邻接校验、行军粮、行军记录全部按出发城算。
- `pickArmy(state, armyId, cityId)`：举义后按城取兵；举义前队伍还挂在本地主城（id=1，与战略城不是一套编号），此时不按城筛。
- 到达结算后队伍驻城归位：胜则进驻新占城，败/平退回出发城。打下第二座城之后，那座城就能继续出兵。
- 城池窗口的出征块新增「出发城」下拉（多城时），并显示该城可出兵力。

### Bug B：内政/征兵页写死 `cityId: 1`
- 排查中发现真实情况比报告更绕：`city.facilities` 用的是**本地地图主城 id**，`army.cityId` 用**战略城 id**，两套编号。
- 处理结果：
  - 设施/府库仍走本地主城 id（`city.citys[0].cityId`），语义正确；
  - 征兵/编队走当前城（战略 id），分城有了自己的队伍；
  - 旧档队伍缺 `cityId` 时并到本城。

## 二、行军改距离驱动（率土口径）

```
行军日 = ceil( 里程km ÷ (55 × 速度/100) )，夹在 1~12 日
速度 = 队内最慢武将，60 + 五维speed/100 （约 60~160）
里程 = conf/campaign/strategy/map.json 每条 route 自带的 km
```

- 相邻城约 105~135 km、队速 134 → 2 日，与旧基线一致，不破坏既有平衡。
- 337 km 长途、步卒队 → 7 日；骑兵队 → 5 日。
- 辎重队速度固定 70，运输按同公式算。
- 前端行军线仍按 `(现在 - departDay) / (arriveDay - departDay)` 插值；因为时长随距离增长，屏幕上军标速度才恒定（旧实现固定 2 日，远城军标跑得飞快，正好说反）。

## 三、战法距离配置化

新增 `conf/skills-range.json`：

| 项 | 作用 |
|---|---|
| `derive` | 按「效果类型 × 单体/群体」推导默认距离：物理 3/4、谋略 4/5、控制 3/4、治疗与增益 9 |
| `ranges` | 逐战法覆盖（cfgId → 距离），策划手感调参入口 |
| `attackDistance` | 普攻攻击距离：盾 3 / 弓 4 / 骑 3，`overrides` 可按武将 cfgId 覆盖 |

- 战场三槽 = 前锋 0 / 中军 1 / 大营 2；跨阵营距离 = 双方槽位和 + 1（1~5）。
- 普攻现在**受攻击距离约束**：大营里的短手武将打不到敌大营（距离 5），只有战法能越排。前排还在时大营仍能打到敌前锋（距离 3），所以不会僵死。
- 距离不足时群体战法命中人数自然变少（先按射程过滤、再取前 N）。
- 描述从「（射程3）」升级为「（有效距离 4 · 3 人）」，与内核同源。
- 编队界面每槽显示「攻距 N · 可及敌前锋/中军/大营」，超距标红。

## 四、城市不再是同质化的一座座数字

### 12 维属性全部接进经济
| 属性 | 落到哪 |
|---|---|
| 农业 / 商业 | 逐城日产（已有），现在再加民心系数 |
| 兵源 | `devArms` 兵营开发度 → 征兵工期 |
| 城防 | `devDef` 城防开发度 → 守军 |
| 民心 | 人口增长（+2%~6%/月）、粮金产量（×0.85~1.10）、治安 |
| 治安 | 灾害概率（×0.7~1.0）、城防任务加成 |
| 灾害风险 | 灾害掷骰（已有） |

### 开发度 LV1~5 + 委任成长
- `devLevel`：0-23 / 24-47 / 48-71 / 72-95 / 96+ → Lv1~5。
- 五项官职（农政/商事/军备/城防/人事）**推动官员驻在城的开发度**：每旬一次，按官员对应属性（0.5~1.5 倍），开发度越高涨得越慢（100 以上 ×0.3），出征中的官员收益减半。
- 所以「派谁去边城」本身是内政决策，而不是把人都堆在首都。

### 民心/治安的真实后果
- 围城 −3/旬、城库低于 500 粮 −2/旬、灾害 −3~−5、城破 −15 民心 / −12 治安。
- 征兵抽丁伤民心（抽走该城人口的 10% ≈ 民心 −20）。
- 治安越高灾害越少。

## 五、内政页重构

- 页签改为：概览 / 内政 / 征兵 / 武将 / 酒馆 / 战报 /（主城多一个）府库。
- **内政页对所有权城统一**：治理卡（民心、治安、四项等级、人口、城库）+ 五项任务
  - 开垦 300（农田 +3）
  - 招商 300（市集 +3）
  - 募兵整编 350（兵营 +3、民心 +1）
  - 修筑城防 400（城防 +2、治安 +2、守军 +150）
  - 开仓赈灾 500（解除减产、民心 +6、治安 +3；无灾时不可点）
- 府库页（仅主城）：府库资源、设施升级、存档三档位 + 导入导出、军情、章节结局。原来这些塞在"内政"页，主城与分城共用一套设施，容易误解。

## 六、招募与出仕

- **出仕**（新增）：每旬按名声掷骰（城数×8 + 武将×2 + 君主魅力/100，概率 3%~45%），在野贤才主动来投，优先投奔籍贯在我方城里的人。版图越大越容易来人。
- **三顾之礼**（新增）：探索登庸失败会累积好感，同一人下次成功率 +12%（最多 95%），toast 会提示「已拒 N 次，再访更易」。
- 招降、战俘、酒馆来访维持原样。
